# Sandoghchi Model Routing Policy

## Low Risk Tasks

Examples:
- Documentation
- Formatting
- Simple analysis

Preferred:
Free models


## Medium Risk Tasks

Examples:
- Tests
- Small refactors
- Non-critical code

Preferred:
Cheap coding models


## High Risk Tasks

Examples:
- Sync V1
- Database
- Migration
- Production logic

Required:
Strong reasoning model
Mandatory review


Escalation:

Free model failure
        |
        v
Cheap paid model
        |
        v
Strong model
